# Vue3-Admin 项目开发文档

欢迎查阅 `vue3-admin` 项目开发与架构文档！本项目是一个基于 Vue 3、Element Plus、TypeScript 且由 Webpack 5 驱动的现代中后台管理系统前端解决方案。

本系列文档旨在帮助新成员快速上手项目，并深入理解本项目的工程化配置与核心架构设计。

## 文档目录

我们为您细分了以下几个维度的文档，您可以直接点击进入查阅：

1. **[🚀 快速开始指引 & 启动流程](./getting_started.md)**
   记录了项目开发环境的基础要求、环境配置的区别（如 mock、debug）以及常用 NPM 启动/构建脚本说明。

2. **[🏗️ 项目架构与技术栈说明](./architecture.md)**
   从整体架构角度阐明使用的核心技术栈、项目目录结构语义，以及诸如全局按需引入、状态管理（Pinia）、以及基于 Axios 二次封装的接口请求机制。

3. **[🛣️ 路由与权限控制指南](./routing_and_permission.md)**
   由于中后台管理系统的菜单、路由体系通常较为复杂。这里专门记录了本项目核心的**“前端固定路由”**同**“动态后台获取路由”**兼容的双重鉴权与渲染设计。

4. **[📏 代码开发与工程化提交规范](./standard_and_norm.md)**
   为保障多开发者协同，这里说明了项目中 Eslint、StyleLint、Prettier 的联合格式化策略，以及如何使用 `cz` 命令标准化提交 Git Commit。
